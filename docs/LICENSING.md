# 许可

登记库采用复合许可：代码一个许可，条目内容各自声明。

## 代码

检查器、脚本、工作流、网站代码、Worker：Apache-2.0，见 `LICENSE`。

## 条目内容

每条表述（`Conjectures/<猜想>/S<编号>.lean` 和同名 `.json`）按其元数据中 `license` 字段声明的许可发布。可选：

| SPDX 标识 | 名称 |
| --- | --- |
| `CC-BY-4.0` | 知识共享 署名 4.0（默认，全文见 `LICENSE-CONTENT`） |
| `CC-BY-SA-4.0` | 知识共享 署名-相同方式共享 4.0 |
| `CC0-1.0` | CC0 公有领域贡献 |
| `Apache-2.0` | Apache 许可证 2.0 |
| `MIT` | MIT 许可证 |

规则：

1. **原创表述**：提交者自选，不选即为 CC-BY-4.0。
2. **改编或照录的表述**：必须显式声明许可，并与原作许可一致或兼容；文件头保留原作版权声明，写明做了哪些改动，`source.url` 指向原文。CI 会拒绝没有声明许可的改编条目。
3. **编辑已有条目**（来源备注、非正式复述、外部链接、声明证明等）：提交即同意按该条目的许可发布你的修改，和维基百科相同。
4. **猜想页**（`conjecture.json`：名称、自然语言表述、参考资料）：CC-BY-4.0。
5. 条目的许可一经登记不通过网页编辑更改；确需更正的，由维护者核实后修改，并在提交说明里写明原因。

许可只决定别人怎样使用条目内容，与表述是否被收录无关：收录与否只看是否通过 CI。

本说明不构成法律意见。对具体作品能否这样使用有疑问的，请咨询专业人士或直接联系原作者。
