## 一句人话

任取一个正整数：如果是偶数就除以 2，如果是奇数就乘 3 再加 1。对结果反复这样做，最终都会到达 1。

从 6 开始：`6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1`。从 27 开始则要绕 111 步、一度爬到 9232 才回到 1。这就是考拉兹猜想（Collatz conjecture），也叫 3n+1 猜想。

## 代码逐字读

条目 #20261014-03 的 Lean 代码是：

```lean
∀ n : ℕ, 0 < n → ∃ m : ℕ, (fun k : ℕ => if Even k then k / 2 else 3 * k + 1)^[m] n = 1
```

从左到右读：

- `∀ n : ℕ, 0 < n →`：对任意一个正整数 n。
- `fun k : ℕ => if Even k then k / 2 else 3 * k + 1`：考拉兹映射——遇到偶数 k 取 k/2，遇到奇数 k 取 3k+1。
- `^[m]`：Mathlib 的函数迭代记号，f^[m] 表示把函数 f 连续作用 m 次。
- `∃ m : ℕ, ... = 1`：存在某个有限的迭代次数 m，使得到第 m 步时结果正好是 1。

也就是说，代码只断言一件事：**从任何正整数出发，经过有限次操作一定到达 1。**

## 为什么值得说

它的规则简单到小学生也能玩，却没有人能证明它。这个问题在 20 世纪 30 年代由考拉兹提出，至今未决。计算机已经验证了极大范围的起始数，但始终没有找到普遍理由。2019 年陶哲轩证明了：对任意一个随 N 趋于无穷、哪怕增长得再慢的函数 f，几乎所有起始数 N（按对数密度计算）的轨道最终都会降到 f(N) 以下。注意这里的“高度”是 f(N)，依赖于起始数本身，而不是一个固定的数——所以它仍然不是猜想本身。

## 一点说明

这条写法只要求“到达 1”，没有额外写出关于循环的其他断言。本库只记录代码字面所写，不判断它是否完整表达了原猜想。
