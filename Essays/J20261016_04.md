## 一句人话

黎曼 ζ 函数可以先理解为一个由级数定义、再被解析延拓到整个复平面的函数。它在复平面上有许多零点，其中在 -2、-4、-6、…… 这些负偶数上的零点称为“平凡零点”；除此之外的零点称为“非平凡零点”。黎曼猜想说：**所有非平凡零点的实部都是 1/2**，也就是它们都落在复平面上那条被称为“临界线”的竖直线上。

## 代码逐字读

条目 #20261014-08 直接采用 Mathlib 里的 `RiemannHypothesis` 定义，展开后是：

```lean
∀ (s : ℂ), riemannZeta s = 0 →
  (¬ ∃ n : ℕ, s = -2 * (n + 1)) → s ≠ 1 → s.re = 1 / 2
```

从左到右读：

- `∀ (s : ℂ)`：对任意一个复数 s。
- `riemannZeta s = 0 →`：只要 s 是黎曼 ζ 函数的零点。
- `¬ ∃ n : ℕ, s = -2 * (n + 1)`：并且不存在自然数 n 使 s 等于 -2*(n+1)，即排除了 -2、-4、-6、…… 这些平凡零点。
- `s ≠ 1`：并且 s 不是 1（ζ 函数在 1 处是一个极点，不是零点）。
- `s.re = 1 / 2`：那么 s 的实部等于 1/2。

所以它的字面意思是：**ζ 函数的每个零点，只要不是平凡零点、也不是极点，就必须落在实部 1/2 上。**

## 为什么值得说

黎曼猜想是克雷数学研究所的千禧年大奖难题之一，与素数分布有深刻联系：它以及一些相关命题控制着“小于某个数的素数有多少个”这类问题的估计误差。人类已经数值验证了数量极其庞大的零点全部落在临界线上，也证明了至少有四成的非平凡零点在临界线上，但完整证明仍然空缺。
