## 一句人话

哥德巴赫猜想说的是：**每一个大于 2 的偶数，都可以写成两个素数之和。**

比如 `4 = 2 + 2`、`6 = 3 + 3`、`8 = 3 + 5`、`10 = 3 + 7`、`100 = 47 + 53`。这里的素数就是只能被 1 和自己整除的正整数（2、3、5、7、11、13……）。这个命题的最早表述出自 1742 年哥德巴赫写给欧拉的信（那时还把 1 当作素数，信中的形式也与今天不同）；现在通行的“每个大于 2 的偶数是两个素数之和”是欧拉在回信中整理出来的形式。它至今没有被证明。

## 代码逐字读

条目 #20261014-01 的 Lean 代码是：

```lean
∀ n : ℕ, 2 < n → Even n → ∃ p q : ℕ, Nat.Prime p ∧ Nat.Prime q ∧ n = p + q
```

从左到右读：

- `∀ n : ℕ`：对任意一个自然数 n。
- `2 < n →`：只要 n 大于 2，那么……
- `Even n →`：并且 n 是偶数。在 Mathlib 里，`Even n` 表示存在某个 r 使得 n = r + r，即 n 是某个数的两倍。
- `∃ p q : ℕ`：就存在两个自然数 p 和 q。
- `Nat.Prime p ∧ Nat.Prime q`：p 和 q 都是自然数意义上的素数。
- `n = p + q`：而且 n 恰好等于 p 加 q。

合起来就是：**凡是大于 2 的偶数，都能找到两个素数把它凑出来。**

条目 #20261014-02 的形状完全一样，只是把 `Nat.Prime` 换成了一般环论意义上的 `Prime`：

- `Nat.Prime` 是“自然数里的素数”，意思是大于等于 2、只有 1 和自己两个正因子的数。
- `Prime` 是代数里的“素元”概念：一个元素非零、不是单位，并且它整除乘积 a * b 时，必定整除 a 或整除 b。在自然数上，它与 `Nat.Prime` 等价，Mathlib 里对应的定理是 `Nat.prime_iff`。

## 为什么值得说

这个命题的难点不在理解，而在证明：计算机已经把它验证到非常大的数（公开的计算结果在 4×10^18 以上都没有找到反例），但验证到任何有限的数都不构成证明——没有人能保证下一个偶数不会出问题。数学需要的是对“所有”偶数都成立的理由。

## 一点说明

本库只登记“这条 Lean 命题说了什么”，不判断它与原猜想是否等价。这里的形式化把“偶数”写成 n 大于 2 且 `Even n`，把“素数”交给 Mathlib 的定义；至于这是否就是哥德巴赫的本意，留给数学家在线下讨论。
